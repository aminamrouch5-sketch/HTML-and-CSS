# GIT CREATE NEW REPO AS NEW USER
1-  Install git
2- setup my user github name : 
    git config --global user.name "Your Name"
3- setup my email github :
    git config --global user.email "your.email@example.com"
4- to see git config : 
    git config --list
5- add a repo commontaire before push it to github :
    git commit -m "Initial commit"
6- git push -origine main
